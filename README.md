# 🥖 鲍师傅盲盒抢购助手

---

## 项目背景

Too Good To Go 上的鲍师傅盲盒，每次开售几秒内就没了，并且存在大量倒卖。

作者在又一场"22:47 开售、准时血战"的抢购中败北后，产生了这个项目

- 本工具的用途是**用你自己的真实账号、抢一份留着自己吃的盲盒**。
- **如果你打算用它来批量抢购倒卖——你正是这个项目想讲述的那个问题本身。**请直接关掉这个页面。

## 下载与使用

**v0.0.3 预发布版已上线**：在 [Releases](../../releases) 页下载 `MasterBunBakeryGrabber-v0.0.3-x64.exe`（约 18 MB，Windows x64，单文件免安装），双击运行。

- 启动即菜单：首次运行引导 邮箱+验证码 登录（官方登录方式）；
- 菜单 1 配置支付卡 CVV；菜单 2 开始抢购：到开售时刻自动出手；
- Ctrl+C 随时中止，停止后回到菜单。

**使用前提：**需要先在官方 App 内**绑定过支付卡**——支付走你账号中已保存的那张卡；若需银行验证，会自动引导完成。

**测试边界：**支付环节目前仅使用**中行卓隽 MasterCard** 测试通过；其他银行卡的可用性不确定。预发布版本，偶有粗糙在所难免。
